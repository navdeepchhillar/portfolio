# Navdeep — 3D Portfolio

A single-page 3D portfolio (Three.js) in a black / cyan / violet theme.

Files:
- `index.html` — the whole site (HTML + CSS + JS; loads Three.js and Google Fonts from CDNs)
- `Navdeep_Resume.pdf` — the resume behind the "Resume" buttons
- `og-banner.png` — preview image when the link is shared

## Put it online (free, ~2 minutes)

**Option A — Netlify Drop (easiest)**
1. Go to https://app.netlify.com/drop
2. Drag the whole `navdeep-portfolio` folder onto the page.
3. You get a live link like `https://<name>.netlify.app` (you can rename it in Site settings).

**Option B — GitHub Pages**
1. Create a repo named `navdeepchhillar.github.io` on github.com/navdeepchhillar.
2. Upload these 3 files to it.
3. Settings → Pages → Branch: `main` → Save. Live at `https://navdeepchhillar.github.io`.

**Option C — Vercel**
1. https://vercel.com/new → import the repo from Option B (or drag the folder).
2. Deploy — live at `https://<name>.vercel.app`.

## Add it to LinkedIn
- Profile → **Contact info** (pencil) → **Website** → paste the link, type "Portfolio".
- Featured → **+** → **Add a link** → paste the link.
